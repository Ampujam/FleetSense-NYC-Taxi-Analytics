
# FleetSense – NYC Taxi Analytics

## Project Overview
FleetSense is a Data Science and Analytics project
focused on NYC Yellow Taxi trip data.

The goal is to analyze taxi demand, revenue,
trip patterns, and operational performance.

## Technologies
- Python
- DuckDB
- SQL
- pandas
- PyArrow
- Streamlit

## Dataset
NYC TLC Yellow Taxi Trip Records
January 2025 – December 2025

## Completed Tasks
- Downloaded 12 months of taxi data
- Set up VS Code and Python environment
- Installed required Python libraries
- Inspected sample taxi records
- Identified dataset columns and data types

## Work in Progress
- Monthly trip count analysis
- Data cleaning and validation
- Data warehouse development
- Dashboard development
